# **Virtual Fitting Room App (Check-Outfit)**  
**GitHub Repository Description**  

🚀 **Welcome to the Virtual Fitting Room App ("Check-Outfit")!** 👗👔  

This repository contains a **real-time augmented reality (AR) application** that allows users to **simulate how clothes fit** before wearing them. The app uses **computer vision (MediaPipe)** to track body pose and overlay virtual outfits on the user in real-time via the smartphone camera.  

### **📌 Key Features**  
✔ **Real-time outfit simulation** – Visualize clothes on your body before trying them on  
✔ **Multiple outfit options** – Switch between T-shirts, dresses, jackets, etc.  
✔ **Body landmark detection** – Uses **MediaPipe Pose Landmarker** for accurate positioning  
✔ **Android-compatible** – Built with **Kotlin, CameraX, and Jetpack Compose** (optional)  
✔ **Responsive UI** – Simple and intuitive controls  

### **🛠 Tech Stack**  
- **Kotlin** (Primary language)  
- **Android SDK & CameraX** (Camera handling)  
- **MediaPipe** (Pose detection & body tracking)  
- **OpenCV** (Image processing – optional for advanced features)  
- **Jetpack Compose** (Modern UI – if implemented)
